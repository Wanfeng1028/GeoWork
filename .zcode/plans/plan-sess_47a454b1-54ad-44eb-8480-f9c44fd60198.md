# Ant Design X 迁移计划（doc/25 新建）

## 决策（用户已确认方向，细节按推荐项）
- **自研组件保留但入口关闭**：不删代码，用开关切走
- **开关默认 X 版**（`aiComponentsV2: true`），设置页实验特性区留 Switch 可切回
- **范围**：仅主对话页 NewTaskPage（homeView + conversationView）；右侧 AssistantChatPanel 旁路面板本期不动
- **分两期**，每期独立提交、独立验收、文档同步

## 核心架构：只换渲染层，不动数据层
`useSession(convId)` → `ConversationSnapshot` 是唯一数据源（messages/thinkingSteps/toolCalls/fileDiffs/workflow/pendingApproval）。自研组件只是渲染层。因此：
- **Session 对象层、SSE 状态机、conversationCache 全部不动**
- 新建 `pages/NewTask/components/antdx/` 渲染树，与自研树并列，NewTaskPage 按开关二选一
- **最大化复用既有资产**：MarkdownStream（A2）、DiffViewer（A4）、ContextPickerModal、ApprovalCard、WorkflowRunCard 直接挂进 X 组件的插槽，不重造

## 一期：核心会话回路（本次提交）

### 1. 依赖与开关
- `npm install @ant-design/x@^2.9.0 --workspace apps/desktop`（peerDeps antd ^6.1.1，项目 6.5.2 兼容）
- `GeoWorkSettings` 加 `aiComponentsV2: boolean`（默认 `true`）+ `DEFAULT_SETTINGS`；SettingsPage `renderExperimental` 加 Switch 行（照抄 generativeUi 那行）
- `electron.vite.config.ts` manualChunks 加 `vendor-antdx`（@ant-design/x 及其 mermaid/react-syntax-highlighter 依赖独立 chunk，避免撑大 vendor-antd）

### 2. antdx 渲染树（新目录 `pages/NewTask/components/antdx/`）
- **`ConversationX.tsx`**：antd-x `Bubble.List` 渲染 `snap.messages`，`virtual` 虚拟滚动 + 贴底跟随（替代 A5 手写的 @tanstack/react-virtual 逻辑，仅 X 分支）；审批卡片（复用 ApprovalCard）仍渲染在列表上方
- **`MessageBubbleX.tsx`**：单条消息 → `Bubble`
  - user：纯文本右对齐
  - assistant：`messageRender` = MarkdownStream（复用）；`loading` 态对应 streaming
  - thinkingSteps → antd-x `ThoughtChain`（折叠，streaming 自动展开）
  - toolCalls → 复用 ToolCallTimeline（挂 Bubble footer/下方）
  - fileDiffs → 复用 DiffViewer（已懒加载）
  - workflow → 复用 WorkflowRunCard（仅末条 assistant）
- **`SenderX.tsx`**：antd-x `Sender` 替代 ChatComposer
  - onSubmit/onCancel → handleSend/handleStop
  - header 区：上下文选择入口（skill/expert/mcp → ContextPickerModal）+ 工作目录 Dropdown + ModelPicker
  - SelectedContextBar chip 条
- **`WelcomeX.tsx`**：antd-x `Welcome` + `Prompts` 替代 homeView hero（Prompts 先用 WORK_MODE_COPY 文案占位，点击填入输入框）

### 3. NewTaskPage 接线
- 顶部 `const useAntdx = loadSettings().aiComponentsV2`
- homeView / conversationView 各按开关分流：`useAntdx ? <WelcomeX/> : 旧 hero`、`useAntdx ? <ConversationX/> : 旧 messageList+composer`
- 自研组件 import 保留（开关切回时仍可用）

### 4. 测试 + 验收
- 新增 `antdx/__tests__/`：ConversationX 渲染（user/assistant/streaming/thinkingSteps/fileDiffs）、SenderX 发送/停止、开关分流（aiComponentsV2 true/false 各渲染对应树）
- 验收：tsc + vitest 全绿 + build（确认 vendor-antdx 独立 chunk、主包不膨胀）+ 边界检查
- 文档：新建 `doc/25-AntDesignX-Migration.md`、AGENT.md v1.12 + §14、CHANGELOG

## 风险与对策
- **@ant-design/x 包体积**：依赖含 mermaid/react-syntax-highlighter，用 vendor-antdx 独立 chunk + 仅 NewTaskPage 懒加载 chunk 引用，不进首屏
- **Bubble.List 虚拟滚动动态高度**：antd-x 基于 rc-virtual-list 支持动态测量；若实测异常，回退复用 A5 的 @tanstack/react-virtual 包装
- **开关非响应式**：settings 是快照读取，切换后需路由切换/刷新生效（与 demoMode 惯例一致，可接受）
- **不删自研代码**：边界检查/lint 不会因死代码报错（自研组件仍被开关分支引用）
