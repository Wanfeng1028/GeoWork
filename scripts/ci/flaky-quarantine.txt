# Flaky 测试隔离清单（P4）——当前为空。
#
# 用法（每行一个 Go 测试名或 / 正则片段，# 开头为注释）：
#   TestValidateWrite
#   TestRoutes/subtest_name
#
# CI 会把非注释行用 '|' 拼接传给 `go test -skip`，被隔离的测试不再参与
# 门禁判定。规则（doc/16 §10）：
#   1. 同一提交两次 CI run 结果不一致（一绿一红）即可判定 flaky；
#   2. 隔离必须附 issue 编号的 TODO 注释与本文件条目，双处可追溯；
#   3. 隔离超过 30 天仍未修复的，从清单移除并删除测试（宁缺毋滥）。
