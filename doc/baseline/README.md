# 设计基线截图

> **状态：待创建**
> 本目录用于存放设计系统视觉基线截图，待 F0-1 验收时填充。

## 用途

根据 `01-GeoWorkFrontend-Design-System.md` §18.2 的规定，本目录用于：

- 关键页面的全屏截图
- 关键组件的独立截图
- 设计 token 的可视化样本
- 响应式断点截图

## 命名规范

```
{page|component}-{name}-{state}-{breakpoint}.{png|jpg}
```

示例：
- `page-dashboard-default-1440.png`
- `component-button-primary-hover-1024.png`

## 使用时机

- F0-1 验收时：建立初始基线
- 每个 FP 阶段结束时：更新变更部分
- 设计系统 token 变更时：同步更新可视化样本
