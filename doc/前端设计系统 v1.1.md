## 15. Antd Token 翻译注意事项（v1.1 新增）

> ⚠️ **Antd Alpha 派生陷阱**

Antd v6 设置 `colorPrimary` 后，会自动派生 `colorPrimaryHover`、`colorPrimaryActive`、`colorPrimaryBg`、`colorPrimaryBorder` 等约 10 个变体。这些派生色使用 antd 内部的色彩算法（基于 HSL 旋转和明度调整），**往往与你手写的色值不一致**，尤其在高饱和度青色上会发灰。

**必须做的事：**

```ts
// editorialDarkTheme.ts 示例
export const editorialDarkTheme: ThemeConfig = {
  algorithm: theme.darkAlgorithm,
  token: {
    colorPrimary: '#3AD9FF',
    // 不要只写 colorPrimary 就完事，必须显式覆写以下派生：
    colorPrimaryHover: '#5ce1ff',
    colorPrimaryActive: '#2bc4ea',
    colorPrimaryBg: 'rgba(58, 217, 255, 0.10)',
    colorPrimaryBorder: 'rgba(58, 217, 255, 0.25)',
    colorPrimaryTextHover: '#5ce1ff',
    colorPrimaryText: '#3AD9FF',
    colorPrimaryTextActive: '#2bc4ea',
  },
  components: {
    Button: {
      // 如果 token 级覆写仍不够，在组件级再兜底
      primaryColor: '#0a0f1c', // 主按钮文字色
    },
    Menu: {
      itemSelectedBg: 'rgba(58, 217, 255, 0.10)',
      itemSelectedColor: '#3AD9FF',
      itemBorderRadius: 8,
    },
    Card: {
      borderRadiusLG: 12,
    },
  },
}
```

**原则：**

1. 永远不要只设 `colorPrimary` 一个值就期望 antd 派生出你要的效果
2. 本文档中所有 hover / active / bg / border 色值都是**显式覆写目标**
3. 每次改主色后，用 Antd 的 Theme Editor 或 `antd token <Component>` CLI 检查派生结果
4. 如果派生色与文档不一致，以文档为准，在 `components` 级覆写
