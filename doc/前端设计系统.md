## 一、设计原则

1. **骨架克制**：圆角只三档、间距只用 4 的整数倍、阴影极淡。秩序感来自参数一致，不是装饰。
2. **色彩即状态**：颜色的第一职责是让用户一眼分辨 Agent 的 idle / planning / running / waiting / success / failed。
3. **明暗同权**：暗色是 GIS 画布的自然底盘，亮色是会议室投屏刚需。两套同做、同标准、同验收。
4. **品牌原生**：所有色彩从深海军蓝 `#071225` 派生，不从 antd 默认蓝出发。

## 二、主题策略

### 2.1 入口收敛

| 主题 | 状态 |
|---|---|
| 跟随系统 | ✅ 保留（指向 editorial / editorial-dark） |
| **editorial-light（亮色旗舰）** | ✅ 打磨 |
| **editorial-dark（暗色旗舰）** | ✅ 打磨 |
| 晴空 light / 暗色 dark / 插画 / 玻璃 | ⛔ 关闭入口（代码保留，随时可复活） |

「关闭」只动用户可见的菜单（AppMenu 的 themeChildren + 设置页中的主题选项），主题文件和 `themes/index.ts` 一行不动，保证 React Hooks 顺序稳定。

### 2.2 切换契约

- 明暗切换时**层级不变、只变明暗**：同一组件在两套里的视觉深度完全一致。
- 所有 Token 必须同时给出明/暗两版本，禁止只写一套。

| 角色 | 色值 | 用途限制 |
|---|---|---|
| 深海军蓝 | `#071225` | 只用于派生暗色背景 |

## 四、形状 / 圆角 / 间距

### 4.1 圆角（三档，禁止散装）

| 档位 | 值 | 用于 |
|---|---|---|
| SM | `4px` | Tag、Badge、代码块、Tooltip、小图标容器 |
| MD | `8px` | 按钮、输入框、Select、菜单项、卡片内元素 |
| LG | `12px` | 卡片、弹窗、下拉面板、对话气泡 |

### 4.2 间距（4 的整数倍）

```
4 · 8 · 12 · 16 · 20 · 24 · 32 · 48
```

- 组件内 padding ≤ 16
- 卡片之间 gap = 12 或 16
- 页面边距 = 24 或 32
- 对话流	max-width 720px 居中

### 4.3 字号与行高

| 级 | 字号 | 行高 | 字重 | 用途 |
|---|---|---|---|---|
| H1 | 20 | 1.4 | 600 | 页面标题 |
| H2 | 16 | 1.5 | 600 | 区块标题 |
| Body | 14 | 1.6 | 400 | 正文 |
| Dialogue | 14 | 1.7 | 400 | Agent 回复（阅读优先） |
| Caption | 13 | 1.5 | 400 | 辅助信息 |
| Small | 12 | 1.4 | 400 | 时间戳 / Tag |

规则：
- 数字、commit hash、坐标、CRS、路径、命令行一律 **`JetBrains Mono`**；
- 侧栏任务标题 = `13px / 500`；时间戳 = `12px / 三级色`。

## 六、组件级规范

### 6.1 Button

| 类型 | dark | light | 备注 |
|---|---|---|---|
| primary | 底 `#3AD9FF` / 文 `#0a0f1c` | 底 `#0e7490` / 文 `#ffffff` | 一个页面最多一个 |
| default | 底 `rgba(255,255,255,0.06)` / 文 一级 | 底 `rgba(15,23,42,0.04)` / 文 一级 | 无边框 |
| ghost | 透明 / 文 二级，hover 出底色 | 同左 | 弱操作 |
| danger | 底 `rgba(255,107,107,0.12)` / 文 `#ff6b6b` | 底 `rgba(220,38,38,0.08)` / 文 `#dc2626` | |
| link | 文 `#3AD9FF` | 文 `#0e7490` | |

- 尺寸：Large 40 / Middle 34 / Small 28（其他高度禁用）
- 圆角 8px
- loading：内嵌 14px Spin，不换文案
- hover/active/disabled　见 3.4

⚠️ antd 6 必须**显式覆写** `colorPrimaryHover / Active / Bg / Border / Text / TextHover / TextActive`，不能只设 `colorPrimary` 交给 antd 派生（会在高饱和青下发灰）。

### 6.2 Menu

| 属性 | dark | light |
|---|---|---|
| 菜单项高度 / 圆角 / padding | 36px / 8px / 12px | 同左 |
| 默认文字 | 二级 | 二级 |
| hover 背景 | `rgba(255,255,255,0.05)` | `rgba(15,23,42,0.04)` |
| 选中背景 | `rgba(58,217,255,0.10)` | `rgba(14,116,144,0.06)` |
| 选中文字 | 一级文字色 | 一级文字色 |
| 左侧指示条 | 2px × `#3AD9FF` | 2px × `#0e7490` |
| 图标 | 16px 线性 | 16px 线性 |

### 6.3 Card

- 背景 = Level 1，边框 = colorBorder，圆角 12px，padding 16px，常态无阴影；
- hover：边框加深 + 背景微亮（亮色 → `#f7f8fa`，暗色 → `#1a2136`），150ms ease-out。

### 6.4 Input / TextArea

- 高度 34px（多行自适应），圆角 8px，边 = colorBorder；
- 背景：dark `rgba(255,255,255,0.04)` / light `rgba(15,23,42,0.03)`；
- placeholder = 三级文字；
- focus：边换主色 + 外发光（3.3 已定义）。

### 6.5 Table

- header 无底色，字 = 二级色 12/500，下边框 = colorBorder；
- 行 hover = `rgba(255,255,255,0.03)` / `rgba(15,23,42,0.02)`；
- 行分割线 = colorBorderSecondary；无斑马纹；
- 单元格 padding 12 16；数字列等宽右对齐。

### 6.6 Modal / Drawer

- 背景 = Level 2（dark）/ Level 1（light），圆角 12px；
- 遮罩：dark `rgba(0,0,0,0.6)` / light `rgba(15,23,42,0.3)`；
- 阴影见 3.3；标题 16/600；关闭 28px ghost。

### 6.7 Tag / Badge

- 圆角 4 / 高 22 / 字 12 / padding 0 8；
- 状态配方完整见 3.4 对应行；
- running 态必须带"点 + 脉冲"（透明度 1↔0.5，1.5s 周期）。

### 6.8 Tooltip / Popover

- 背景：dark `#232d45` / light `#1e293b`；文字白；圆角 4；字 12；padding 6 10；max-width 280。

### 6.9 滚动条（全局）

```css

::-webkit-scrollbar-track { background:transparent }
::-webkit-scrollbar-thumb {
  background: rgba(128,128,128,0.28);
```

## 七、GeoWork 专属组件（v1.1 新增）

> 基础组件决定"丑不丑"，专属组件决定"像不像一套"。以下是 GeoWork 自研结构的强制规格，不允许自由发挥。

### 7.1 Segmented 切换器（顶部 Work/Code/Map 与侧栏 任务/移动端控制 同款）

| 属性 | 值 |
|---|---|
| 容器 | 高度 32，padding 4，底色 `colorBgSpotlight`，圆角 8 |
| 单项 | 高度 24，圆角 6，字号 13/500 |
| 选中 | 底色 `colorBgContainer`（dark：`#121829` / light：`#ffffff`）+ 0.5px `colorBorder` |
| 未选中 | 文字`colorTextSecondary`，hover 切一级 |
| 间距 | 项间 2px |

### 7.2 主能力按钮组（通用 GIS / Auto）

两种合法形态，**只允许二选一**：
- `primary`（认真对待的操作，当页只有一个）
- `ghost`（次级）

**禁止**：同一组里一个紫一个驼。紫色 `#7c3aed` 非品牌色，弃用；"通用 GIS" 主色实心，"Auto" ghost。

### 7.3 对话输入框工具条

| 元素 | 规格 |
|---|---|
| 输入框容器 | max-width 720 居中，距底 16，圆角 10，边`colorBorder`，背景`colorBgContainer` |
| ⊕ 附件钮 | 28×28 ghost，**不做实心色块**，图标 16 |
| 🎤 / 发送 | 28×28 ghost，图标 16；发送键在可发送态转 primary 实心 |
| 状态条 | 左下角一行 12px tertiary：`模型名 · 上下文` |

### 7.4 运行状态 Tag

| 状态 | 配方 |
|---|---|
| 进行中 | 主色（亮：`#0e7490` / 暗：`#3AD9FF`）+ 前置脉冲点，**禁止灰** |
| 已完成 | 成功青 + 勾 |
| 失败 | 红 + 叉 |

### 7.5 Hero 标题

- 字 20/600 一级色（`#0f172a`），行高 1.2；
- 尾部 `▍` 打字光标视为 bug，禁止；
- 副标题 13 三级色，max-width 560 居中。

### 7.6 顶栏右侧图标组

- 所有功能图标 = 16px ghost、28px 点击区；
- 窗口控制按钮（min/max/close）在最右、视觉与功能图标分组。

## 九、动效规范

| 场景 | 时长 | 缓动 | 属性 |
|---|---|---|---|
| hover | 150ms | ease-out | bg / border |
| 面板展开 | 200ms | ease-out | width, opacity |
| Modal | 200ms | ease-out | opacity + translateY(-8→0) |

## 变更记录

### v1.1（2026-08-11）— 自 v1.0 的演进

**变更**
1. 色板整体从暖灰 stone 切换为深空冷色（brand-native），对齐深海军蓝/信号蓝/地理青/沙金的品牌色；

4. 文字色阶由"色值"改为"四等级语义"（一级/二级/三级/四级）；
5. 明/暗各自给出完整五组状态色（主色/成功/警告/错误/中性），Agent 状态色独立成节；
6. 新增：antd Alpha 派生陷阱警告及显式覆写清单；
7. 新增：GeoWork 专属组件规格（Segmented / 主能力按钮 / 输入框工具条 / 运行状态 Tag / Hero / 顶栏图标组）；
8. 新增：动效规范、滚动条、空状态、可访问性底线；
9. 主题入口由 7 项收敛为 3 项（跟随系统 / 亮色 / 暗色）；
10. 文档治理：v1.0 封存，v1.1 并入本文件作为权威版，后续版本内部迭代不再新起文件。
