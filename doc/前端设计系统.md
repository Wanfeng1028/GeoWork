## 一、设计原则

1. **骨架克制**：圆角只三档、间距只用 4 的整数倍、阴影极淡。秩序感来自参数一致，不是装饰。
2. **色彩即状态**：颜色的第一职责是让用户一眼分辨 Agent 的 idle / planning / running / waiting / success / failed。
3. **明暗同权**：暗色是 GIS 画布的自然底盘，亮色是会议室投屏刚需。两套同做、同标准、同验收。
4. **品牌原生**：所有色彩从深海军蓝 `#071225` 派生，不从 antd 默认蓝出发。

## 二、主题策略

### 2.1 入口收敛

| 主题 | 状态 |
|---|---|
| 跟随系统 | ✅ 保留（指向 editorial / editorial-dark） |
| **editorial-light（亮色旗舰）** | ✅ 打磨 |
| **editorial-dark（暗色旗舰）** | ✅ 打磨 |
| 晴空 light / 暗色 dark / 插画 / 玻璃 | ⛔ 关闭入口（代码保留，随时可复活） |

「关闭」只动用户可见的菜单（AppMenu 的 themeChildren + 设置页中的主题选项），主题文件和 `themes/index.ts` 一行不动，保证 React Hooks 顺序稳定。

### 2.2 切换契约

- 明暗切换时**层级不变、只变明暗**：同一组件在两套里的视觉深度完全一致。
- 所有 Token 必须同时给出明/暗两版本，禁止只写一套。

## 四、形状 / 圆角 / 间距

### 4.1 圆角（三档，禁止散装）

| 档位 | 值 | 用于 |
|---|---|---|
| SM | `4px` | Tag、Badge、代码块、Tooltip、小图标容器 |
| MD | `8px` | 按钮、输入框、Select、菜单项、卡片内元素 |
| LG | `12px` | 卡片、弹窗、下拉面板、对话气泡 |

### 4.2 间距（4 的整数倍）

```
4 · 8 · 12 · 16 · 20 · 24 · 32 · 48
```

- 组件内 padding ≤ 16
- 卡片之间 gap = 12 或 16
- 页面边距 = 24 或 32
- 对话流	max-width 720px 居中

### 4.3 字号与行高

| 级 | 字号 | 行高 | 字重 | 用途 |
|---|---|---|---|---|
| H1 | 20 | 1.4 | 600 | 页面标题 |
| H2 | 16 | 1.5 | 600 | 区块标题 |
| Body | 14 | 1.6 | 400 | 正文 |
| Dialogue | 14 | 1.7 | 400 | Agent 回复（阅读优先） |
| Caption | 13 | 1.5 | 400 | 辅助信息 |
| Small | 12 | 1.4 | 400 | 时间戳 / Tag |

规则：
- 数字、commit hash、坐标、CRS、路径、命令行一律 **`JetBrains Mono`**；
- 侧栏任务标题 = `13px / 500`；时间戳 = `12px / 三级色`。

## 七、布局骨架

> 原则：**主区只有一种"内骨"**——对话流和工作台共用同一套布局，只是内容不同。
> 原则：**收起无痕**——面板收起时既不显示把手，也不留下可见的边框或背景块。
> 原则：**开合在顶栏**——所有面板的展开/收起按钮都放在顶栏，不藏在悬停区或角落里。

### 7.1 三段式 Agent 工作区

GeoWork 全站只有一种整体骨架：

```
┌────────┬───────────────────────┬─────────────────┐
│ rail   │   主区                 │   右侧面板        │
│ 一级导航│  (对话/画布/表单)        │  (工具/上下文)    │
│  56px  │   灵活宽度               │   320px 可调      │
│        │                       │   可整体隐藏       │
└────────┴───────────────────────┴─────────────────┘
     ↑               ↑                    ↑
 一级入口          正在干啥的工作区        工具/面板
 (新任务/         输入底吸 (对话页)      (审查/终端/
  定时任务/                              辅助对话/…)
  扩展/…)
```

| 区块 | 宽度 | 职责 | 说明 |
|---|---|---|---|
| rail | 固定 56px | 一级功能入口 | 图标 + tooltip，永不展开文字 |
| 主区 | flex 1 | 当前工作内容 | 对话流 / 地图工作台 / 表单 / 列表 |
| 右侧面板 | 320px，可拖拽 240–480 | 工具/上下文 | **常驻第三列**，收起后主区占满无残留 |

**铁律（不可违反）：**
1. **面板开合控制点只在顶栏**——展开/收起按钮永远在顶栏右侧一组功能图标里，不允许藏在悬停区；"收起"后该位置没有任何把手、边框或背景残留。
2. **主区内骨唯一**——对话流页和地图工作台只是"内容换料"，骨架（输入框吸底、单列居中、间距节奏）完全一样。
3. **右侧永不出现"隐藏的提示条"**——收起后屏幕右边就是干净的 Level 0 背景，没有灰色细条、没有把手。

### 7.2 12 列隐形网格系统

所有水平宽度对齐到同一套"刻度"，不可见但强制：

```
|col|col|col|col|col|col|col|col|col|col|col|col|
 ←- gutter 16px (内容≥1920) / 12px (1280-1919) / 8px (<1280) -→
```

水平刻度（宽度→对应的可见区块）：

| 刻度 | 用于 |
|---|---|
| 56px | rail（一级导航） |
| 260px | 侧栏二级导航（展开） |
| 320px | 右侧面板（默认） |
| 720px | 对话流内容宽度（居中） |
| 48px | 卡片 padding-l/r |
| 24px | 页面 padding |

**规则**：任何元素宽度必须是"刻度值"或"刻度值的整倍数"。不允许出现 712px、350px 这种"自己编的尺寸"。

## 八、反馈状态三件套

> 任何页面在任何时刻都必须落在"有数据 / 加载中 / 空状态 / 报错"四种之一，不允许"留白"。

### 8.1 骨架屏（加载中）

按页面模板选用：

| 模板 | 骨架形态 |
|---|---|
| A 对话流 | 4 条消息骨架（宽 60%/80%/70%/90% 错落的灰条） + 底部输入框占位 |
| B 工作台 | 左树 = 8 行树节点骨架条；地图区 = 浅灰网格占位底 |
| C 列表 | 页头标题骨架 + 6 行表格骨架（行高 48） |
| D 表单 | 标题骨架 + 5 组字段骨架（label 条 + input 条） |

通用样式：
- 骨架条背景 = `colorFillSecondary`，顶部一层微光（dark `rgba(255,255,255,0.04)` / light `rgba(15,23,42,0.05)`）从左到右 1.5s 循环；
- 圆角 = 它要占位的那个元素的圆角；
- 禁用：满屏居中大菊花（antd Spin）——骨架优先于 spinner。

### 8.2 空状态（无数据）

按第十节"空状态设计"执行。骨架→空态切换时**布局不跳变**：两者的标题位置、引导按钮位置在同一像素。

### 8.3 报错（操作失败/网络异常）

**位置分级**：

| 级别 | 形态 | 用法 |
|---|---|---|
| 字段级 | 文字红 + 字段底淡红 | 表单校验失败 |
| 块级 | 卡片状态条（左侧 3px 红条） | 某个模块失败 |
| 页面级 | 页头下方一条横幅（48px 高，淡红底） | 整个页面加载失败 |
| 全局级 | 右上角滑出 toast（8s 自动消失，可关闭） | 网络断开等跨页 |

**文案规则**：错误提示只说"是什么 + 怎么办"两件事，不贴原始异常堆栈。原始堆栈放 toast 的"复制详情"里。

**重试**：页面级 / 块级报错必须带「重试」ghost 按钮；字段级不带按钮，靠重新输入消除。

## 十一、动效规范

| 场景 | 时长 | 缓动 | 属性 |
|---|---|---|---|
| hover | 150ms | ease-out | bg / border |
| 面板展开 | 200ms | ease-out | width, opacity |
