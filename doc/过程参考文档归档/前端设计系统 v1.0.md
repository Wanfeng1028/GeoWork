# GeoWork 桌面端设计系统 v1.0

> ⚠️ **历史存档**：本文件为初始版本，仅作历史追溯，即日起不再改动。后续所有迭代请见权威文档 `前端设计系统.md`。

> **定位**：AI Agent 工具，不是后台管理系统。
> **气质**：深空冷色 / 工程精确 / 状态可读。
> **适用范围**：`apps/desktop` 全部界面（Electron + React + antd 6）。
> **品牌来源**：根目录 `README.md`（深海军蓝 / 地理青 / 信号蓝 / 沙金）。

---

## 一、设计原则

1. **骨架克制**：圆角只有 3 档、间距只有整数倍、阴影极淡。界面"直爽"来自秩序，不是装饰。
2. **色彩即状态**：颜色不为好看，为"用户一眼看懂 Agent 现在在干嘛"服务。四种语义状态必须分清（见状态色阶）。
3. **明暗同权**：暗色是 GIS 画布的自然底盘，亮色是会议室投屏刚需。两套同做、同标准、同验收，不分主次。
4. **品牌原生**：所有色彩都从深海军蓝 `#071225` 一色派生，不从 antd 默认蓝出发。

## 二、主题策略

### 2.1 保留与关闭

| 主题 | 状态 | 说明 |
|---|---|---|
| 跟随系统 | ✅ 保留 | 入口，解析到明/暗两套 |
| editorial（亮色旗舰） | ✅ 保留并打磨 | 主方案 |
| editorial-dark（暗色旗舰） | ✅ 保留并打磨 | 主方案 |
| 晴空（light） | ⛔ 关闭入口（代码保留） | antd 默认味来源 |
| 暗色（dark） | ⛔ 关闭入口（代码保留） | 只有一行 `darkAlgorithm` |
| 插画（illustration） | ⛔ 关闭入口（代码保留） | 实验性 |
| 玻璃（glass） | ⛔ 关闭入口（代码保留） | 未来接缝：改造为地图浮动面板的局部材质 |

「关闭」只动用户可见/可选的入口（AppMenu 的 themeChildren、设置页选项），主题文件与 `themes/index.ts` 一行不动，保证 Hooks 顺序稳定、随时可复活。

### 2.2 主题切换契约

- 切换明暗时**层级不变、只变明暗**：同一组件在两套里的深度层级完全一致。
- 所有 token 必须同时给出明/暗两版本，禁止只写一套。

## 三、色彩系统

### 3.1 品牌原色（README 定义）

| 角色 | 色值 | 用途限制 |
|---|---|---|
| 深海军蓝 | `#071225` | 只用于派生暗色背景，不直接用作 UI 底色 |
| 信号蓝 | `#3AD9FF` | **仅暗色装饰/发光**，禁直接用于亮色文本/主按钮 |
| 地理青 | `#8BFFE2` | **仅暗色成功/高亮**，禁直接用于亮色文本 |
| 沙金 | `#F4D77E` | **仅暗色警告**，禁直接用于亮色文本 |

⚠️ 可访问性注意：`#3AD9FF / #8BFFE2 / #F4D77E` 在白底上的对比度约 1.6:1，全部不达 WCAG。它们必须经"可访问性换算"才能进亮色主题（见 3.3）。

### 3.2 暗色主题（editorial-dark）

**背景阶梯**（从深海军蓝派生，冷热比 10:1）：

| Token | 值 | 用于 |
|---|---|---|
| colorBgLayout | `#0a0f1c` | 窗口底色 |
| colorBgContainer | `#121829` | 侧栏/卡片/面板 |
| colorBgElevated | `#1b2338` | 浮层/弹窗/下拉 |
| colorBgSpotlight | `#242f4a` | hover 底色 |
| colorFillSecondary | `rgba(255,255,255,0.04)` | 表格条纹/弱分隔区 |

**边框**（极淡，用明度代替色相）：

| Token | 值 |
|---|---|
| colorBorder | `rgba(255,255,255,0.08)` |
| colorBorderSecondary | `rgba(255,255,255,0.04)` |

**文字四阶**（冷白，slate 系，不是暖白）：

| Token | 值 | 用途 |
|---|---|---|
| colorText | `rgba(226,232,240,0.95)` | 主文字 |
| colorTextSecondary | `rgba(226,232,240,0.65)` | 次文字 |
| colorTextTertiary | `rgba(226,232,240,0.45)` | 提示/时间戳 |
| colorTextQuaternary | `rgba(226,232,240,0.28)` | 占位/禁用 |

### 3.3 亮色主题（editorial）

**背景阶梯**（冷灰白，slate 系，不是 stone 暖纸）：

| Token | 值 |
|---|---|
| colorBgLayout | `#f7f8fa` |
| colorBgContainer | `#ffffff` |
| colorBgElevated | `#ffffff`（靠阴影分层） |
| colorBgSpotlight | `#f1f4f8` |
| colorFillSecondary | `rgba(15,23,42,0.03)` |

**边框**：

| Token | 值 |
|---|---|
| colorBorder | `rgba(15,23,42,0.10)` |
| colorBorderSecondary | `rgba(15,23,42,0.06)` |

**文字四阶**（冷黑，slate 系）：

| Token | 值 |
|---|---|
| colorText | `#0f172a` |
| colorTextSecondary | `#334155` |
| colorTextTertiary | `#64748b` |
| colorTextQuaternary | `#94a3b8` |

### 3.4 状态色阶（核心，两个主题分别指定，不可共用）

| 状态 | 亮色（可访问变体） | 暗色（品牌原色） | 语义 |
|---|---|---|---|
| 主色 / 正在执行 | `#0e7490` (cyan-700) | `#3AD9FF` | running / primary / link |
| 成功 / 完成 | `#0f766e` (teal-700) | `#8BFFE2` | success / completed |
| 警告 / 等待确认 | `#b45309` (amber-700) | `#F4D77E` | warning / pending |
| 错误 / 失败 | `#b91c1c` (red-700) | `#f87171` (red-400) | error / failed |
| 信息 / 中性弱提示 | `#334155` | `#94a3b8` | info / disabled |

**配色比率（防止花）**：
- 60% 中性背景：背景阶梯
- 30% 中性容器：colorBgContainer + 卡片
- 9% 状态色：上面五个状态，只在状态位出现
- 1% 品牌高亮：`#3AD9FF/#8BFFE2` 仅用于 logo、图标点缀、暗色下的细发光边

## 四、形状 / 圆角 / 间距

### 4.1 圆角（全站收敛为 3 档，不再散装）

| Token | 值 | 用于 |
|---|---|---|
| borderRadiusSM | `4px` | code 块、小徽标、tag |
| borderRadius | `6px` | 按钮、输入框、下拉、菜单项 |
| borderRadiusLG | `10px` | 卡片、弹窗、面板 |

禁用值：`0px`（原方案的全直角一致性不够）、`2px`、`8px`（antd 默认）、`12px+`。

### 4.2 间距（4 的整数倍）

```
4 · 8 · 12 · 16 · 20 · 24 · 32 · 48
```
- 组件内部 padding ≤ 16
- 卡片之间 gap = 12/16
- 页面边距 = 24/32
- 主区单列最大宽度 = 760px（对话/文档），居中对齐

### 4.3 阴影

亮色用"纸下压"小阴影，暗色用"环境光"：

| 主题 | 值 |
|---|---|
| 亮色 浮层 | `0 1px 2px rgba(15,23,42,0.06), 0 8px 24px rgba(15,23,42,0.06)` |
| 暗色 浮层 | `0 1px 2px rgba(0,0,0,0.4), 0 8px 24px rgba(0,0,0,0.35)` |

**卡片常态无阴影**，只在浮起/hover 时出现，层级靠"背景色阶 + 阴影"表达，不靠更粗的边框。

## 五、字体与排版

| 角色 | 栈 |
|---|---|
| 正文/界面 | `'Inter', 'MiSans', 'PingFang SC', 'Microsoft YaHei', sans-serif` |
| 代码/数字/commit | `'JetBrains Mono', 'IBM Plex Mono', monospace` |

规则：
- 基础字号 `13px`，正文行高 `1.6`，对话/文档内容行高 `1.65`；
- 所有 commit hash、数字、坐标、路径、`npx/npm` 命令**强制等宽字体**；
- 标题不重排版：页面主标题 `20px/600`，区块标题 `15px/600`，更小的用 `13px/500 + 文字色阶` 表达层级，不再往下加字号。

## 六、组件设计规范

### 6.1 按钮（Button）

| 类型 | 亮色 | 暗色 | 用法 |
|---|---|---|---|
| primary | 底 `#0e7490` / 文 `#fff` | 底 `#3AD9FF` / 文 `#07101f` | 全局只有一个 |
| default | 无框/底 `rgba(15,23,42,0.04)` hover 加深 | 无框/底 `rgba(255,255,255,0.04)` hover 加深 | 主要操作 |
| danger | 红 700 系 | 红 400 系 | 破坏性操作 |
| ghost/link | 文 `#0e7490` | 文 `#3AD9FF` | 次级 |

- 圆角统一 `6px`，高度 `32px`（小号 26 / 大号 40），禁用其他高度；
- primary 一个页面最多出现一次；其他一律 default/ghost；
- 加载态：主按钮内左侧 14px spinner，不换文案。

### 6.2 状态徽标 / Tag

- 圆角 `4px`，不带图标时用文字+语义色；
- 状态色必须来自 3.4 色阶（running=主色、success=青、warning=琥珀、error=红），禁用 antd 默认彩虹色板；
- 正在执行的状态需要 **脉冲动画**（透明度 1 → 0.5 → 1，周期 1.5s），静态色不够。

### 6.3 卡片 / 面板（Card）

- 圆角 `10px`，边框 `1px colorBorder`，常态**无阴影**；
- hover：暗色 -> border 变 `colorBorderSecondary` 加强 + 背景上到 `colorBgElevated`；亮色同理；
- 卡片标题统一 `15px/600`，与内容之间用 `colorBorderSecondary` 细线分隔，不用加重底色。

### 6.4 输入框（Input / TextArea）

- 圆角 `6px`，高度 `32px`，边框色 `colorBorder`；
- focus 态：边框换主色 + 1px `rgba(主色,0.3)` 外发光（暗色下用 `#3AD9FF` 30%，亮色下用 `#0e7490` 30%）；
- 占位符颜色用 `colorTextQuaternary`，不再写死 `#bfbfbf`。

### 6.5 菜单 / 列表项（Menu / List）

- 选中态：**左侧 2px 主色条 + 淡底色**（不整块变色）；
  - 亮色：底色 `rgba(14,116,144,0.08)`、条 `#0e7490`
  - 暗色：底色 `rgba(58,217,255,0.10)`、条 `#3AD9FF`
- hover：背景 `colorBgSpotlight`，150ms 过渡；
- 右侧时间戳/弱信息用 `colorTextTertiary + 12px + 等宽数字`；
- 菜单项行高 `36px`，图标统一 `16px`（line 风格，不要 filled）。

### 6.6 对话流（Chat / Message）

Agent 脸面，单独定：

| 元素 | 规则 |
|---|---|
| 布局 | 单列居中，max-width 760px，左右大量留白 |
| 用户消息 | 右对齐，浅底气泡（`colorFillSecondary`），圆角 10px，无头像 |
| Agent 消息 | 左对齐，**无气泡**，直接铺底，靠排版层级区分 |
| 工具调用卡 | 卡片容器，header 行 = 图标 + 工具名 + 耗时 + 状态点；body 为等宽参数/结果；
- running：状态点主色脉冲
- success：状态点青
- failed：状态点红 + 边框染红 |
| 思考过程 | 默认收起，一行「已工作 N 秒 >」可展开，展开内容字色 `colorTextSecondary` |
| 输入框 | 固定吸底，max-width 760px，圆角 10px，发送键主色 |

### 6.7 表格（Table）

- 去掉 header 底色，改为**底部一条横线 + header 字色 `colorTextTertiary`**（Linear 式）；
- 行与行用 `colorBorderSecondary` 细线分隔，不用斑马纹（GIS 大量数据时斑马纹晃眼）；
- hover 行背景 `colorBgSpotlight`；
- 数字列等宽 + 右对齐。

### 6.8 弹窗 / 抽屉（Modal / Drawer）

- 圆角 `10px`，阴影用 4.3 的浮层阴影（不要 antd 默认大投影）；
- 头部只留标题 + 关闭按钮，不加分割线；
- 遮罩：暗色 `rgba(0,0,0,0.6)` / 亮色 `rgba(15,23,42,0.35)`。

### 6.9 滚动条（全站统一）

```css
/* 示意 */
::-webkit-scrollbar { width: 8px; height: 8px; }
::-webkit-scrollbar-track { background: transparent; }
::-webkit-scrollbar-thumb {
  background: rgba(128,128,128,0.28);
  border-radius: 4px;
}
::-webkit-scrollbar-thumb:hover { background: rgba(128,128,128,0.45); }
```
- 隐藏原生粗滚动条，所有面板统一 8px；
- 轨道透明，滑块半透明，仅在 hover 时加深。

### 6.10 空状态（Empty）

- 不放默认 antd Empty 插画；
- 结构 = **一行问候语/标题（20px/600）+ 一行说明（13px/tertiary）+ 最多 3 张建议卡**（对应 ZCode 首页的模板卡）；
- 建议卡 = 图标 + 标题 + 一行描述，hover 上浮 1px + 阴影。
